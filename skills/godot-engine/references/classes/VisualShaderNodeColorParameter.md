# VisualShaderNodeColorParameter

**Inherits:** VisualShaderNodeParameter

A Color parameter to be used within the visual shader graph.

Translated to `uniform vec4` in the shader language.

## Properties

- `default_value: Color` = `Color(1, 1, 1, 1)` — A default value to be assigned within the shader.
- `default_value_enabled: bool` = `false` — Enables usage of the `default_value`.
