# PrismMesh

**Inherits:** PrimitiveMesh

Class representing a prism-shaped PrimitiveMesh.

Class representing a prism-shaped PrimitiveMesh.

## Properties

- `left_to_right: float` = `0.5` — Displacement of the upper edge along the X axis. 0.0 positions edge straight above the bottom-left edge.
- `size: Vector3` = `Vector3(1, 1, 1)` — Size of the prism.
- `subdivide_depth: int` = `0` — Number of added edge loops along the Z axis.
- `subdivide_height: int` = `0` — Number of added edge loops along the Y axis.
- `subdivide_width: int` = `0` — Number of added edge loops along the X axis.
