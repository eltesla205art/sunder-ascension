# MUSIC SETUP — drop your tracks here

The game's AudioManager auto-loads these files. Just add them with these exact
names and they play immediately — no code changes needed:

| File | When it plays | Loop? |
|------|---------------|-------|
| `main_theme.ogg` | Ship select + all stages (heroic galaxy theme) | yes |
| `boss_theme.ogg` | When any boss appears (intense) | yes |
| `victory.ogg` | Final victory screen (optional) | no |

`.ogg` preferred (Godot loops it seamlessly). `.mp3` also works as a fallback.
