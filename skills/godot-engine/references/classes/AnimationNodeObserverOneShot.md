# AnimationNodeObserverOneShot

**Inherits:** AnimationNodeObserver

Observer for events from AnimationNodeOneShot instances.



## Signals

- `fade_in_finished()` — Emitted when the one-shot has finished fading in.
- `fade_out_started()` — Emitted when the one-shot has started fading out.
- `finished()` — Emitted when the one-shot has finished.
- `started()` — Emitted when the one-shot has started.
