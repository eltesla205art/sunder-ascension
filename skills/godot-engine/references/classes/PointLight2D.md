# PointLight2D

**Inherits:** Light2D

Positional 2D light source.

Casts light in a 2D environment. This light's shape is defined by a (usually grayscale) texture.

## Properties

- `height: float` = `0.0` — The height of the light.
- `offset: Vector2` = `Vector2(0, 0)` — The offset of the light's `texture`.
- `texture: Texture2D` — Texture2D used for the light's appearance.
- `texture_scale: float` = `1.0` — The `texture`'s scale factor.
