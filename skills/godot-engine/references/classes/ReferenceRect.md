# ReferenceRect

**Inherits:** Control

A rectangular box for designing UIs.

A rectangular box that displays only a colored border around its rectangle (see `Control.get_rect`). It can be used to visualize the extents of a Control node, for testing purposes.

## Properties

- `border_color: Color` = `Color(1, 0, 0, 1)` — Sets the border color of the ReferenceRect.
- `border_width: float` = `1.0` — Sets the border width of the ReferenceRect.
- `editor_only: bool` = `true` — If `true`, the ReferenceRect will only be visible while in editor.
