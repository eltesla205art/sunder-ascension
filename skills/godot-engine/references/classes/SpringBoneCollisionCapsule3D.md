# SpringBoneCollisionCapsule3D

**Inherits:** SpringBoneCollision3D

A capsule shape collision that interacts with SpringBoneSimulator3D.

A capsule shape collision that interacts with SpringBoneSimulator3D.

## Properties

- `height: float` = `0.5` — The capsule's full height, including the hemispheres.
- `inside: bool` = `false` — If `true`, the collision acts to trap the joint within the collision.
- `mid_height: float` — The capsule's height, excluding the hemispheres.
- `radius: float` = `0.1` — The capsule's radius.
