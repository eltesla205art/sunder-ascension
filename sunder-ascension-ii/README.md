Everything for the sequel lives in this folder, kept separate from the
original *SUNDER: Ascension — The Nine Bows* (`web/`, `godot/`, `docs/`), which is unchanged.

| Path | What it is |
|---|---|
| `DESIGN.md` | Storyline, gameplay ideas, PS5-style UI direction, prompt pack |
| `art/` | Concept art: key art A/B, Scarab Warbringer Mk II A/B, Mk II hangar shots A/B |
| `web/game.html` | Sequel build, starting from a copy of the Part 1 game. So far it adds the Mk II hangar backdrop (from `art/hangar-mk2-a.webp`) to the ship-select screen |
