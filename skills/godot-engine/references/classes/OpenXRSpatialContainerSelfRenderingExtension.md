# OpenXRSpatialContainerSelfRenderingExtension

**Inherits:** OpenXRExtensionWrapper

OpenXR extension that defines "self rendering" for spatial containers.

OpenXR extension that defines "self rendering" for spatial containers. A self rendered spatial container's pixels are all generated by an app and submitted to the runtime using standard OpenXR swapchains and composition layers.

## Methods

- `is_enabled() -> bool` *const* — Returns `true` if spatial container self rendering is enabled in the project settings and available on the current runtime.
