# EditorResourcePreviewGenerator

**Inherits:** RefCounted

Custom generator of previews.

Custom code to generate previews. Check `EditorSettings.filesystem/file_dialog/thumbnail_size` to find a proper size to generate previews at.

## Methods

- `_can_generate_small_preview() -> bool` *virtual const* — If this function returns `true`, the generator will call `_generate` or `_generate_from_path` for small previews as well.
- `_generate(resource: Resource, size: Vector2i, metadata: Dictionary) -> Texture2D` *virtual required const* — Generate a preview from a given resource with the specified size.
- `_generate_from_path(path: String, size: Vector2i, metadata: Dictionary) -> Texture2D` *virtual const* — Generate a preview directly from a path with the specified size.
- `_generate_small_preview_automatically() -> bool` *virtual const* — If this function returns `true`, the generator will automatically generate the small previews from the normal preview texture generated by the methods `_generate` or `_generate_from_path`.
- `_handles(type: String) -> bool` *virtual required const* — Returns `true` if your generator supports the resource of type `type`.
- `request_draw_and_wait(viewport: RID) -> void` *const* — Call from within `_generate` to request the rendering server draw to the `viewport`.
