# RDTextureView

**Inherits:** RefCounted

Texture view (used by RenderingDevice).

This object is used by RenderingDevice.

## Properties

- `format_override: RenderingDevice.DataFormat` = `232` — Optional override for the data format to return sampled values in.
- `swizzle_a: RenderingDevice.TextureSwizzle` = `6` — The channel to sample when sampling the alpha channel.
- `swizzle_b: RenderingDevice.TextureSwizzle` = `5` — The channel to sample when sampling the blue color channel.
- `swizzle_g: RenderingDevice.TextureSwizzle` = `4` — The channel to sample when sampling the green color channel.
- `swizzle_r: RenderingDevice.TextureSwizzle` = `3` — The channel to sample when sampling the red color channel.
