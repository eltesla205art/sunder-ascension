# LightmapGIData

**Inherits:** Resource

Contains baked lightmap and dynamic object probe data for LightmapGI.

LightmapGIData contains baked lightmap and dynamic object probe data for LightmapGI. It is replaced every time lightmaps are baked in LightmapGI.

## Properties

- `light_texture: TextureLayered` *(deprecated)* — The lightmap atlas texture generated by the lightmapper.
- `lightmap_textures: TextureLayered[]` = `[]` — The lightmap atlas textures generated by the lightmapper.
- `shadowmask_textures: TextureLayered[]` = `[]` — The shadowmask atlas textures generated by the lightmapper.

## Methods

- `add_user(path: NodePath, uv_scale: Rect2, slice_index: int, sub_instance: int) -> void` — Adds an object that is considered baked within this LightmapGIData.
- `clear_users() -> void` — Clear all objects that are considered baked within this LightmapGIData.
- `get_user_count() -> int` *const* — Returns the number of objects that are considered baked within this LightmapGIData.
- `get_user_path(user_idx: int) -> NodePath` *const* — Returns the NodePath of the baked object at index `user_idx`.
- `is_using_spherical_harmonics() -> bool` *const* — If `true`, lightmaps were baked with directional information.
- `set_uses_spherical_harmonics(uses_spherical_harmonics: bool) -> void` — If `uses_spherical_harmonics` is `true`, tells the engine to treat the lightmap data as if it was baked with directional information.

## Enum ShadowmaskMode

- `SHADOWMASK_MODE_NONE = 0` — Shadowmasking is disabled.
- `SHADOWMASK_MODE_REPLACE = 1` — Shadowmasking is enabled.
- `SHADOWMASK_MODE_OVERLAY = 2` — Shadowmasking is enabled.
