# NoiseTexture2D

**Inherits:** Texture2D

A 2D texture filled with noise generated by a Noise object.

Uses the FastNoiseLite library or other noise generators to fill the texture data of your desired size. NoiseTexture2D can also generate normal map textures. The class uses Threads to generate the texture data internally, so `Texture2D.get_image` may return `null` if the generation process has not completed yet. In that case, you need to wait for the texture to be generated before accessing the image and the generated byte data:

## Properties

- `as_normal_map: bool` = `false` — If `true`, the resulting texture contains a normal map created from the original noise interpreted as a bump map.
- `bump_strength: float` = `8.0` — Strength of the bump maps used in this texture.
- `color_ramp: Gradient` — A Gradient which is used to map the luminance of each pixel to a color value.
- `generate_mipmaps: bool` = `true` — Determines whether mipmaps are generated for this texture.
- `height: int` = `512` — Height of the generated texture (in pixels).
- `in_3d_space: bool` = `false` — Determines whether the noise image is calculated in 3D space.
- `invert: bool` = `false` — If `true`, inverts the noise texture.
- `noise: Noise` — The instance of the Noise object.
- `normalize: bool` = `true` — If `true`, the noise image coming from the noise generator is normalized to the range `0.0` to `1.0`.
- `resource_local_to_scene: bool` = `false` — 
- `seamless: bool` = `false` — If `true`, a seamless texture is requested from the Noise resource.
- `seamless_blend_skirt: float` = `0.1` — Used for the default/fallback implementation of the seamless texture generation.
- `width: int` = `512` — Width of the generated texture (in pixels).
