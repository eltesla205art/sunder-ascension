# SegmentShape2D

**Inherits:** Shape2D

A 2D line segment shape used for physics collision.

A 2D line segment shape, intended for use in physics. Usually used to provide a shape for a CollisionShape2D.

## Properties

- `a: Vector2` = `Vector2(0, 0)` — The segment's first point position.
- `b: Vector2` = `Vector2(0, 10)` — The segment's second point position.
