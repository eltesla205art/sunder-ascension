# VisualShaderNodeVec3Parameter

**Inherits:** VisualShaderNodeParameter

A Vector3 parameter to be used within the visual shader graph.

Translated to `uniform vec3` in the shader language.

## Properties

- `default_value: Vector3` = `Vector3(0, 0, 0)` — A default value to be assigned within the shader.
- `default_value_enabled: bool` = `false` — Enables usage of the `default_value`.
