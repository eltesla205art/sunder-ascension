# Title logo swap

The title screen shows a built-in vector "SUNDER / ASCENSION" logo by default.

To use your Higgsfield logo instead:
1. Download the SUNDER: Ascension logo from Higgsfield.
2. Rename it to exactly:  title_logo.png
3. Drop it in this folder (assets/sprites/).

That's it — the title screen auto-detects the file and shows it instead of the
vector text. No code changes. (Recommended: 16:9, transparent or black background.)
