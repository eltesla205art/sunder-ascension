# RDAttachmentFormat

**Inherits:** RefCounted

Attachment format (used by RenderingDevice).

This object is used by RenderingDevice.

## Properties

- `format: RenderingDevice.DataFormat` = `36` — The attachment's data format.
- `samples: RenderingDevice.TextureSamples` = `0` — The number of samples used when sampling the attachment.
- `usage_flags: int` = `0` — The attachment's usage flags, which determine what can be done with it.
