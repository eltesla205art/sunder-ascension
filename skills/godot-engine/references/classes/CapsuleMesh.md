# CapsuleMesh

**Inherits:** PrimitiveMesh

Class representing a capsule-shaped PrimitiveMesh.

Class representing a capsule-shaped PrimitiveMesh.

## Properties

- `height: float` = `2.0` — Total height of the capsule mesh (including the hemispherical ends).
- `radial_segments: int` = `64` — Number of radial segments on the capsule mesh.
- `radius: float` = `0.5` — Radius of the capsule mesh.
- `rings: int` = `8` — Number of rings along the height of the capsule.
