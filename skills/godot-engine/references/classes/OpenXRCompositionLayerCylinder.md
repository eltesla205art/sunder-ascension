# OpenXRCompositionLayerCylinder

**Inherits:** OpenXRCompositionLayer

An OpenXR composition layer that is rendered as an internal slice of a cylinder.

An OpenXR composition layer that allows rendering a SubViewport on an internal slice of a cylinder.

## Properties

- `aspect_ratio: float` = `1.0` — The aspect ratio of the slice.
- `central_angle: float` = `1.5707964` — The central angle of the cylinder.
- `fallback_segments: int` = `10` — The number of segments to use in the fallback mesh.
- `radius: float` = `1.0` — The radius of the cylinder.
