# TorusMesh

**Inherits:** PrimitiveMesh

Class representing a torus PrimitiveMesh.

Class representing a torus PrimitiveMesh.

## Properties

- `inner_radius: float` = `0.5` — The inner radius of the torus.
- `outer_radius: float` = `1.0` — The outer radius of the torus.
- `ring_segments: int` = `32` — The number of edges each ring of the torus is constructed of.
- `rings: int` = `64` — The number of slices the torus is constructed of.
