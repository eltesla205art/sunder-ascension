# VisualShaderNodeVec2Parameter

**Inherits:** VisualShaderNodeParameter

A Vector2 parameter to be used within the visual shader graph.

Translated to `uniform vec2` in the shader language.

## Properties

- `default_value: Vector2` = `Vector2(0, 0)` — A default value to be assigned within the shader.
- `default_value_enabled: bool` = `false` — Enables usage of the `default_value`.
