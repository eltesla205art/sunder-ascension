# MarginContainer

**Inherits:** Container

A container that keeps a margin around its child controls.

MarginContainer adds an adjustable margin on each side of its child controls. The margins are added around all children, not around each individual one. To control the MarginContainer's margins, use the `margin_*` theme properties listed below. Note: The margin sizes are theme overrides, not normal properties.

## Theme items

- `margin_bottom: int` (constant) = `0`
- `margin_left: int` (constant) = `0`
- `margin_right: int` (constant) = `0`
- `margin_top: int` (constant) = `0`
