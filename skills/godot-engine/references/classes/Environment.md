# Environment

**Inherits:** Resource

Resource for environment nodes (like WorldEnvironment) that define multiple rendering options.

Resource for environment nodes (like WorldEnvironment) that define multiple environment operations (such as background Sky or Color, ambient light, fog, depth-of-field...). These parameters affect the final render of the scene. The order of these operations is: - Depth of Field Blur - Auto Exposure - Glow - Tonemap - Adjustments

## Properties

- `adjustment_brightness: float` = `1.0` — Applies a simple brightness adjustment to the rendered image after tonemaping.
- `adjustment_color_correction: Texture` — The Texture2D or Texture3D lookup table (LUT) to use for the built-in post-process color grading.
- `adjustment_contrast: float` = `1.0` — Increasing `adjustment_contrast` will make dark values darker and bright values brighter.
- `adjustment_enabled: bool` = `false` — If `true`, enables the `adjustment_*` properties provided by this resource.
- `adjustment_saturation: float` = `1.0` — Applies a simple saturation adjustment to the rendered image after tonemaping.
- `ambient_light_color: Color` = `Color(0, 0, 0, 1)` — The ambient light's Color.
- `ambient_light_energy: float` = `1.0` — The ambient light's energy.
- `ambient_light_sky_contribution: float` = `1.0` — Defines the amount of light that the sky brings on the scene.
- `ambient_light_source: Environment.AmbientSource` = `0` — The ambient light source to use for rendering materials and global illumination.
- `background_camera_feed_id: int` = `1` — The ID of the camera feed to show in the background.
- `background_canvas_max_layer: int` = `0` — The maximum layer ID to display.
- `background_color: Color` = `Color(0, 0, 0, 1)` — The Color displayed for clear areas of the scene.
- `background_energy_multiplier: float` = `1.0` — Multiplier for background energy.
- `background_intensity: float` = `30000.0` — Luminance of background measured in nits (candela per square meter).
- `background_mode: Environment.BGMode` = `0` — The background mode.
- `fog_aerial_perspective: float` = `0.0` — If set above `0.0` (exclusive), blends between the fog's color and the color of the background Sky, as read from the radiance cubemap.
- `fog_density: float` = `0.01` — The fog density to be used.
- `fog_depth_begin: float` = `10.0` — The fog's depth starting distance from the camera.
- `fog_depth_curve: float` = `1.0` — The fog depth's intensity curve.
- `fog_depth_end: float` = `100.0` — The fog's depth end distance from the camera.
- `fog_enabled: bool` = `false` — If `true`, fog effects are enabled.
- `fog_height: float` = `0.0` — The height at which the height fog effect begins.
- `fog_height_density: float` = `0.0` — The density used to increase fog as height decreases.
- `fog_light_color: Color` = `Color(0.518, 0.553, 0.608, 1)` — The fog's color.
- `fog_light_energy: float` = `1.0` — The fog's brightness.
- `fog_mode: Environment.FogMode` = `0` — The fog mode.
- `fog_sky_affect: float` = `1.0` — The factor to use when affecting the sky with non-volumetric fog.
- `fog_sun_scatter: float` = `0.0` — If set above `0.0`, renders the scene's directional light(s) in the fog color depending on the view angle.
- `glow_blend_mode: Environment.GlowBlendMode` = `1` — The glow blending mode.
- `glow_bloom: float` = `0.0` — The bloom's intensity.
- `glow_enabled: bool` = `false` — If `true`, the glow effect is enabled.
- `glow_hdr_luminance_cap: float` = `12.0` — The higher threshold of the HDR glow.
- `glow_hdr_scale: float` = `2.0` — Smooths the transition between values that are below and above `glow_hdr_threshold` by reducing the amount of glow generated by values that are close to `glow_hdr_threshold`.
- `glow_hdr_threshold: float` = `1.0` — The lower threshold of the HDR glow.
- `glow_intensity: float` = `0.3` — The overall brightness multiplier that is applied to the glow effect just before it is blended with the scene.
- `glow_levels/1: float` = `0.0` — The intensity of the 1st level of glow.
- `glow_levels/2: float` = `0.8` — The intensity of the 2nd level of glow.
- `glow_levels/3: float` = `0.4` — The intensity of the 3rd level of glow.
- `glow_levels/4: float` = `0.1` — The intensity of the 4th level of glow.
- `glow_levels/5: float` = `0.0` — The intensity of the 5th level of glow.
- `glow_levels/6: float` = `0.0` — The intensity of the 6th level of glow.
- `glow_levels/7: float` = `0.0` — The intensity of the 7th level of glow.
- `glow_map: Texture` — The texture that should be used as a glow map to multiply the resulting glow color according to `glow_map_strength`.
- `glow_map_strength: float` = `0.8` — How strong of an influence the `glow_map` should have on the overall glow effect.
- `glow_mix: float` = `0.05` — When using the `GLOW_BLEND_MODE_MIX` `glow_blend_mode`, this controls how much the source image is blended with the glow layer.
- `glow_normalized: bool` = `false` — If `true`, glow levels will be normalized so that summed together their intensities equal `1.0`.
- `glow_strength: float` = `1.0` — The strength that is used when blurring across the screen to generate the glow effect.
- `reflected_light_source: Environment.ReflectionSource` = `0` — The reflected (specular) light source.
- `sdfgi_bounce_feedback: float` = `0.5` — The energy multiplier applied to light every time it bounces from a surface when using SDFGI.
- `sdfgi_cascade0_distance: float` = `12.8` — Note: This property is linked to `sdfgi_min_cell_size` and `sdfgi_max_distance`.
- `sdfgi_cascades: int` = `4` — The number of cascades to use for SDFGI (between 1 and 8).
- `sdfgi_enabled: bool` = `false` — If `true`, enables signed distance field global illumination for meshes that have their `GeometryInstance3D.gi_mode` set to `GeometryInstance3D.GI_MODE_STATIC`.
- `sdfgi_energy: float` = `1.0` — The energy multiplier to use for SDFGI.
- `sdfgi_max_distance: float` = `204.8` — The maximum distance at which SDFGI is visible.
- `sdfgi_min_cell_size: float` = `0.2` — The cell size to use for the closest SDFGI cascade (in 3D units).
- `sdfgi_normal_bias: float` = `1.1` — The normal bias to use for SDFGI probes.
- `sdfgi_probe_bias: float` = `1.1` — The constant bias to use for SDFGI probes.
- `sdfgi_read_sky_light: bool` = `true` — If `true`, SDFGI takes the environment lighting into account.
- `sdfgi_use_occlusion: bool` = `false` — If `true`, SDFGI uses an occlusion detection approach to reduce light leaking.
- `sdfgi_y_scale: Environment.SDFGIYScale` = `1` — The Y scale to use for SDFGI cells.
- `sky: Sky` — The Sky resource used for this Environment.
- `sky_custom_fov: float` = `0.0` — If set to a value greater than `0.0`, overrides the field of view to use for sky rendering.
- `sky_rotation: Vector3` = `Vector3(0, 0, 0)` — The rotation to use for sky rendering.
- `ssao_ao_channel_affect: float` = `0.0` — The screen-space ambient occlusion intensity on materials that have an AO texture defined.
- `ssao_detail: float` = `0.5` — Sets the strength of the additional level of detail for the screen-space ambient occlusion effect.
- `ssao_enabled: bool` = `false` — If `true`, the screen-space ambient occlusion effect is enabled.
- `ssao_horizon: float` = `0.06` — The threshold for considering whether a given point on a surface is occluded or not represented as an angle from the horizon mapped into the `0.0-1.0` range.
- `ssao_intensity: float` = `2.0` — The primary screen-space ambient occlusion intensity.
- `ssao_light_affect: float` = `0.0` — The screen-space ambient occlusion intensity in direct light.
- `ssao_power: float` = `1.5` — The distribution of occlusion.
- `ssao_radius: float` = `1.0` — The distance at which objects can occlude each other when calculating screen-space ambient occlusion.
- `ssao_sharpness: float` = `0.98` — The amount that the screen-space ambient occlusion effect is allowed to blur over the edges of objects.
- `ssil_enabled: bool` = `false` — If `true`, the screen-space indirect lighting effect is enabled.
- `ssil_intensity: float` = `1.0` — The brightness multiplier for the screen-space indirect lighting effect.
- `ssil_normal_rejection: float` = `1.0` — Amount of normal rejection used when calculating screen-space indirect lighting.
- `ssil_radius: float` = `5.0` — The distance that bounced lighting can travel when using the screen space indirect lighting effect.
- `ssil_sharpness: float` = `0.98` — The amount that the screen-space indirect lighting effect is allowed to blur over the edges of objects.
- `ssr_depth_tolerance: float` = `0.5` — The depth tolerance for screen-space reflections.
- `ssr_enabled: bool` = `false` — If `true`, screen-space reflections are enabled.
- `ssr_fade_in: float` = `0.15` — The fade-in distance for screen-space reflections.
- `ssr_fade_out: float` = `2.0` — The fade-out distance for screen-space reflections.
- `ssr_max_steps: int` = `64` — The maximum number of steps for screen-space reflections.
- `tonemap_agx_contrast: float` = `1.25` — Increasing `tonemap_agx_contrast` will make dark values darker and bright values brighter.
- `tonemap_agx_white: float` = `16.29` — The white reference value for tonemapping, which indicates where bright white is located in the scale of values provided to the tonemapper.
- `tonemap_exposure: float` = `1.0` — Adjusts the brightness of values before they are provided to the tonemapper.
- `tonemap_mode: Environment.ToneMapper` = `0` — The tonemapping mode to use.
- `tonemap_white: float` = `1.0` — The white reference value for tonemapping, which indicates where bright white is located in the scale of values provided to the tonemapper.
- `volumetric_fog_albedo: Color` = `Color(1, 1, 1, 1)` — The Color of the volumetric fog when interacting with lights.
- `volumetric_fog_ambient_inject: float` = `0.0` — Scales the strength of ambient light used in the volumetric fog.
- `volumetric_fog_anisotropy: float` = `0.2` — The direction of scattered light as it goes through the volumetric fog.
- `volumetric_fog_density: float` = `0.05` — The base exponential density of the volumetric fog.
- `volumetric_fog_detail_spread: float` = `2.0` — The distribution of size down the length of the froxel buffer.
- `volumetric_fog_emission: Color` = `Color(0, 0, 0, 1)` — The emitted light from the volumetric fog.
- `volumetric_fog_emission_energy: float` = `1.0` — The brightness of the emitted light from the volumetric fog.
- `volumetric_fog_enabled: bool` = `false` — Enables the volumetric fog effect.
- `volumetric_fog_gi_inject: float` = `1.0` — Scales the strength of Global Illumination used in the volumetric fog's albedo color.
- `volumetric_fog_length: float` = `64.0` — The distance over which the volumetric fog is computed.
- `volumetric_fog_sky_affect: float` = `1.0` — The factor to use when affecting the sky with volumetric fog.
- `volumetric_fog_temporal_reprojection_amount: float` = `0.9` — The amount by which to blend the last frame with the current frame.
- `volumetric_fog_temporal_reprojection_enabled: bool` = `true` — Enables temporal reprojection in the volumetric fog.

## Methods

- `get_glow_level(idx: int) -> float` *const* — Returns the intensity of the glow level `idx`.
- `set_glow_level(idx: int, intensity: float) -> void` — Sets the intensity of the glow level `idx`.

## Enum BGMode

- `BG_CLEAR_COLOR = 0` — Clears the background using the clear color defined in `ProjectSettings.rendering/environment/defaults/default_clear_color`.
- `BG_COLOR = 1` — Clears the background using a custom clear color.
- `BG_SKY = 2` — Displays a user-defined sky in the background.
- `BG_CANVAS = 3` — Displays a CanvasLayer in the background.
- `BG_KEEP = 4` — Keeps on screen every pixel drawn in the background.
- `BG_CAMERA_FEED = 5` — Displays a camera feed in the background.
- `BG_MAX = 6` — Represents the size of the `BGMode` enum.

## Enum AmbientSource

- `AMBIENT_SOURCE_BG = 0` — Gather ambient light from whichever source is specified as the background.
- `AMBIENT_SOURCE_DISABLED = 1` — Disable ambient light.
- `AMBIENT_SOURCE_COLOR = 2` — Specify a specific Color for ambient light.
- `AMBIENT_SOURCE_SKY = 3` — Gather ambient light from the Sky regardless of what the background is.

## Enum ReflectionSource

- `REFLECTION_SOURCE_BG = 0` — Use the background for reflections.
- `REFLECTION_SOURCE_DISABLED = 1` — Disable reflections.
- `REFLECTION_SOURCE_SKY = 2` — Use the Sky for reflections regardless of what the background is.

## Enum ToneMapper

- `TONE_MAPPER_LINEAR = 0` — Does not modify color data, resulting in a linear tonemapping curve which unnaturally clips bright values, causing bright lighting to look blown out.
- `TONE_MAPPER_REINHARDT = 1` — A simple tonemapping curve that rolls off bright values to prevent clipping.
- `TONE_MAPPER_FILMIC = 2` — Uses a film-like tonemapping curve to prevent clipping of bright values and provide better contrast than `TONE_MAPPER_REINHARDT`.
- `TONE_MAPPER_ACES = 3` — Uses a high-contrast film-like tonemapping curve and desaturates bright values for a more realistic appearance.
- `TONE_MAPPER_AGX = 4` — Uses an adjustable film-like tonemapping curve and desaturates bright values for a more realistic appearance.

## Enum GlowBlendMode

- `GLOW_BLEND_MODE_ADDITIVE = 0` — Adds the glow effect to the scene.
- `GLOW_BLEND_MODE_SCREEN = 1` — Adds the glow effect to the scene after modifying the glow influence based on the scene value; dark values will be highly influenced by glow and bright values will not be influenced by glow.
- `GLOW_BLEND_MODE_SOFTLIGHT = 2` — Adds the glow effect to the tonemapped image after modifying the glow influence based on the image value; dark values and bright values will not be influenced by glow and mid-range values will be highly influenced by glow.
- `GLOW_BLEND_MODE_REPLACE = 3` — Replaces all pixels' color by the glow effect.
- `GLOW_BLEND_MODE_MIX = 4` — Mixes the glow image with the scene image.

## Enum FogMode

- `FOG_MODE_EXPONENTIAL = 0` — Use a physically-based fog model defined primarily by fog density.
- `FOG_MODE_DEPTH = 1` — Use a simple fog model defined by start and end positions and a custom curve.

## Enum SDFGIYScale

- `SDFGI_Y_SCALE_50_PERCENT = 0` — Use 50% scale for SDFGI on the Y (vertical) axis.
- `SDFGI_Y_SCALE_75_PERCENT = 1` — Use 75% scale for SDFGI on the Y (vertical) axis.
- `SDFGI_Y_SCALE_100_PERCENT = 2` — Use 100% scale for SDFGI on the Y (vertical) axis.
