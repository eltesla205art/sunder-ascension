# SphereMesh

**Inherits:** PrimitiveMesh

Class representing a spherical PrimitiveMesh.

Class representing a spherical PrimitiveMesh.

## Properties

- `height: float` = `1.0` — Full height of the sphere.
- `is_hemisphere: bool` = `false` — If `true`, a hemisphere is created rather than a full sphere.
- `radial_segments: int` = `64` — Number of radial segments on the sphere.
- `radius: float` = `0.5` — Radius of sphere.
- `rings: int` = `32` — Number of segments along the height of the sphere.
